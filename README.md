# x-hide-pinned-tabs

X（旧 Twitter）のホーム上部に勝手に固定される「MLB」などのタブを非表示にする Chrome 拡張。

> **非公式ツールです。** X Corp. および MLB（Major League Baseball）とは一切関係がなく、承認や提携も受けていません。
> 「X」「Twitter」「MLB」は各権利者の商標です。
>
> This is an unofficial tool, not affiliated with or endorsed by X Corp. or Major League Baseball.

## 使い方

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリを clone（または「Code」→「Download ZIP」で展開）したフォルダを選ぶ
4. x.com を開き直すと「MLB」タブが消える

隠すタブ名は、拡張機能の「詳細」→「拡張機能のオプション」で1行1件で変えられる（初期値は `MLB`）。

## 仕組み

- 動くのは `x.com/home` を開いているときだけ。プロフィールや検索などのタブには触らない
- ホームのタブ列（`role="tablist"` の中の `role="tab"`）を監視し、名前が一致するタブを `display: none` にする
- 隠したタブが選択された状態で開いた場合は、残っている先頭のタブ（通常「おすすめ」）に切り替える
- X 側の固定設定そのものは変えない。見た目を隠すだけ

## 注意

- **X の画面が変わると効かなくなることがある。** X の HTML の構造（`role="tablist"` / `role="tab"`）に頼っているため、X の更新で突然タブが隠れなくなることがある
- **隠すのは見た目だけ。** X のアカウント設定やタブの固定は変わらない。拡張を外す・無効にすると元どおり表示される。スマホアプリや他のブラウザには効かない
- **タブ名は表示されている文字と完全一致で判定する**（前後の空白と大文字小文字は無視）。X の表示言語によってタブ名が変わる場合は、オプションで名前を足す
- **データは外部に送らない。** 通信は一切しない。使う権限は `storage`（隠すタブ名の保存）だけで、設定は Chrome の同期機能（`chrome.storage.sync`）に保存される
- **Chrome ウェブストアには出していない。** デベロッパー モードで読み込む必要がある。Chrome の起動時に「デベロッパー モードの拡張機能を無効にする」旨の警告が出ることがある
- 自動では更新されない。新しい版を使うときは、このリポジトリを取り直してから `chrome://extensions` で再読み込みする
- 無保証。利用は自己責任で（詳しくは [LICENSE](LICENSE)）
